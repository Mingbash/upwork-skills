# Screening example — synthetic

**Input:** User has built a spreadsheet-to-email prototype with error logging, has four hours/week and can spend at most 8 Connects per application. Job A asks for a similar workflow, fixed USD 250, no stated deadline; Connects cost unavailable. Job B requires a local researcher in a country the user confirms they cannot work in, fixed USD 400. Account history and balance unavailable.

**Output:** A is a conditional fit based on the supplied prototype; clarify volume, data access and acceptance before final scope/price. Posted USD 250 is a budget, not net revenue or a guaranteed quote. Application cost is unknown, so the 8-Connects limit cannot yet pass. B is excluded for the confirmed location requirement. Account readiness and prior-application status are unverified; this is a fit ranking, not a ready-to-apply shortlist. Demand evidence for both jobs can still enter independent needs analysis.
